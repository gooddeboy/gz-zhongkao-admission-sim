简化广州中考公办高中录取模拟系统 —— 使用说明
================================================

一、启动系统
------------
1. 双击项目根目录的“启动系统.bat”。
2. 会弹出一个黑色命令行窗口，保持它打开。
3. 用浏览器访问：http://127.0.0.1:8000
4. 关闭那个命令行窗口，服务就停止。

注意：不要直接双击 app\static\index.html，那样打不开系统；
      必须先启动 Python 服务，再通过 http://127.0.0.1:8000 访问。


二、各个文件怎么打开
--------------------
启动系统.bat         双击运行，保持窗口打开
docs\设计报告.docx   用 Word 或 WPS 打开
README.md            右键 → 打开方式 → 记事本
docs\*.md            右键 → 打开方式 → 记事本
                     （Windows 默认没有 Markdown 打开程序，双击可能提示
                       “Windows 找不到文件”，这不是文件丢失，是文件关联问题）
requirements.txt     记事本
run.py               PyCharm 或 VS Code
app\*.py             PyCharm 或 VS Code
data\admission.db    SQLite 数据库，不需要直接打开
docs\images\*.png    图片查看器


三、常见问题
------------
1. 浏览器打不开 http://127.0.0.1:8000
   → 本地服务没启动。重新双击“启动系统.bat”，保持窗口打开。

2. 双击 README.md 提示“Windows 找不到文件”
   → 不是文件丢了，是 .md 没有默认打开程序。
     右键文件 → 打开方式 → 记事本，即可查看。

3. 提示端口 8000 被占用
   → 关闭占用 8000 端口的程序，或修改 run.py 里的 port 后重新启动。

4. 设计报告打不开
   → 确认电脑安装了 Word 或 WPS；文件位置：
     docs\设计报告.docx

5. 想重新生成演示数据
   → 打开系统后，在“概览”或“数据管理”里点“生成数据”。


四、目录说明
------------
app\        源代码（投档引擎、数据库、API、前端页面）
data\       数据库、小数据集、滑档案例、运行快照
docs\       设计报告、测试材料、部署说明、演示脚本、截图
tests\      自动化测试（pytest）
scripts\    初始化数据库、生成数据、生成图表和报告
README.md   项目说明（Markdown）
启动系统.bat Windows 一键启动脚本


五、运行测试
------------
在项目目录打开命令行，执行：

    python -m pytest -q

正常结果应为：45 passed。
