# 需求与规则清单

## 1. 项目范围

本系统模拟广州市公办普通高中招生录取的简化流程，面向计算机类专业课程设计。系统不追求完整复现现实政策，而是以任务书规定的简化规则为验收依据。

### 1.1 纳入范围

- 全部考生视为具有公办高中报考资格；
- 只模拟公办普通高中，不含民办、中职、综合高中、港澳班、中外合作项目；
- 第一批只保留自主招生；
- 第二批只保留名额分配（直接录入分配表，不模拟电脑派位）；
- 第三批、第四批为统招；
- 不考虑户籍、区内外、随迁子女、应往届、学籍年限、政策加分、参考科目等级、特长生等；
- 不模拟退档、放弃录取、报到注册、正式补录。

### 1.2 角色与用例

| 角色 | 用例 |
| --- | --- |
| 数据管理员 | 维护高中、初中、考生、计划、资格、志愿；导入 CSV；校验数据；生成演示数据 |
| 招生办操作员 | 新建运行、按批执行/完整运行、查看进度、计划余额、结转流水、一致性校验 |
| 查询用户 | 按考生/高中/计划/批次查询录取结果与未录取原因；导出名单与统计 |
| 分析人员 | 查看计划完成率、分数分布、最低录取分、末位考生；运行滑档案例对照 |

## 2. 规则清单

### R1 批次与志愿上限

| 批次 | 内容 | 志愿上限 |
| --- | --- | --- |
| 第一批 | 自主招生：资格名单、考核排名、计划控制线 | 1 |
| 第二批 | 名额分配：按（高中, 初中）分计划，校内竞争 | 3 |
| 第三批 | 示范性公办高中统招 | 6 |
| 第四批 | 非示范公办高中统招 | 6 |

- 严格按批次 1 → 2 → 3 → 4 执行；
- 考生一旦录取，立即退出本批及后续批次；
- 每所高中只在第三批或第四批之一设置统招接收计划；
- 只有第三批招生高中可以有第一批、第二批计划。

### R2 控制线与梯度线

- 全市公办高中最低控制线 L、第一梯度线 G₁、间隔 Δ 为输入参数，默认 Δ=40；
- 第一梯度：总分 ≥ G₁；
- 第二梯度：G₁−Δ ≤ 总分 < G₁；
- 以此类推，最后一档截至 L；低于 L 不参与录取；
- 分数恰好等于某梯度线时，归入该线对应的较高梯度；
- 计划控制线不得低于 L；
- 学校实际录取最低分在投档完成后由结果产生，不能预先写入录取条件。

### R3 第一批自主招生

- 只对填报该校、在资格名单内、状态合格、总分达到计划控制线的考生；
- 按输入考核排名从前到后录取至满额；
- 考核排名在同一高中内唯一；
- 不实现现实综合成绩计算公式。

### R4 第二至第四批投档

- 每批先处理高梯度，再处理低梯度；
- 同一梯度内先处理第一志愿，再处理第二志愿，依次类推；
- 每一志愿轮次中，对报考同一计划且尚未录取的合格考生，按总分降序、同分序号升序录取，直至计划满额；
- 不得先对每名考生依次扫描全部志愿后再处理下一人；
- 同分序号在同一总分内唯一，数值越小越优先。

### R5 第二批名额分配

- 每个（高中, 初中）有独立计划；
- 考生只能竞争其所属初中获得的名额；
- 不同初中的名额不得互相挤占；
- 第二批同样遵循梯度优先、志愿轮次、分数/同分序号排序。

### R6 批次衔接与计划结转

- 第一批结束后，各高中自主招生剩余名额转入本校第三批统招计划；
- 第二批结束后，先按高中汇总各初中剩余名额，再转入本校第三批统招计划；
- 第三、第四批余缺不互转，最终保留为未完成计划；
- 有效计划数 = 初始计划数 + 转入数；
- 结转只发生一次，重复运行不叠加；
- 必须保留结转流水（来源、去向、人数、批次）。

### R7 计划名额平衡

对每条计划：

```text
初始名额 + 转入数 − 转出数 = 已录取人数 + 剩余名额
```

系统在每次批次执行后校验该等式。

### R8 结果与统计

- 每名考生每次运行最多录取一次；
- 每条计划录取人数不超过有效名额；
- 每条录取记录对应有效志愿，并满足资格与分数要求；
- 最低录取分 = 该计划已录取考生总分最小值；
- 末位考生 = 按该计划实际录取顺序最后录取的人，另报总分、志愿序号、同分序号；
- 二者分别计算，末位考生分数可能高于最低录取分；
- 无人录取时最低分和末位考生均显示“无”，不能用 0 分代替；
- 学校总体统计与分批、分类计划统计分开。

### R9 运行与版本

- 运行前校验数据；
- 支持按批执行和完整运行；
- 每次运行保存输入快照或等价版本依据；
- 已完成运行的输入不得静默修改；
- 重新运行生成独立结果或安全重置，不叠加旧录取；
- 同一快照重复运行结果一致。

### R10 异常输入

以下情况应提示或拒绝：

- 重复考生编号；
- 非法分数（<0 或 >750）；
- 同分且同分序号相同；
- 同一考生同批次重复志愿序号；
- 同一考生同批次重复填报同一高中；
- 无效计划（高中不参加该批次、第二批计划无初中等）；
- 自主招生资格排名重复；
- 计划控制线低于全市控制线；
- 数据锁定后修改输入；
- 已完成或已完成批次重复执行。

## 3. 数据要求

至少包含以下实体或等价关系：

| 实体/关系 | 本系统实现 |
| --- | --- |
| 高中与初中 | `high_schools`、`middle_schools` |
| 考生 | `candidates`（编号、姓名、初中、总分、同分序号） |
| 招生计划 | `admission_plans`（年度、高中、批次、类别、名额、控制线、名额分配初中） |
| 自主招生资格 | `autonomous_qualifications`（考生、高中、状态、考核排名） |
| 志愿 | `volunteers`（年度、考生、批次、志愿序号、目标高中） |
| 模拟运行与结果 | `sim_runs`、`run_admissions`、`run_candidate_results`、`run_candidate_summary` |
| 投档与结转日志 | `run_events`、`run_transfers`、`run_batch_summary` |
| 快照 | `run_snapshots` |

## 4. 简化范围说明

| 任务书项目 | 本系统处理 |
| --- | --- |
| 招生对象 | 全部考生具有公办高中报考资格，不区分户籍等 |
| 招生地域 | 不区分区内外、跨区生，不设区外生比例 |
| 成绩与优先条件 | 只用中考总分和同分序号，不考虑加分、优先录取、参考科目等级 |
| 学校与计划 | 只模拟公办普通高中；第三批/第四批之一设置统招 |
| 第一批 | 只保留自主招生，资格与考核排名直接输入 |
| 第二批 | 直接录入名额分配表，不模拟电脑派位 |
| 其他流程 | 不模拟退档、放弃录取、报到注册、正式补录 |
