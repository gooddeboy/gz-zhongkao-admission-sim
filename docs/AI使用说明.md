# AI 使用说明

任务书允许合理使用 AI 辅助，但要求说明使用环节，并对代码、规则和测试结果负责。本文件说明本项目使用 AI 辅助的范围与人工核验方式。

## 1. 使用环节

| 环节 | AI 辅助内容 | 人工核验 |
| --- | --- | --- |
| 需求梳理 | 将任务书拆分为规则清单、批次流程、数据实体 | 逐条对照任务书；简化范围由人工确认 |
| 数据建模 | 生成 SQLite 表结构草稿、字段说明、ER 图文本 | 人工检查实体关系、唯一约束、外键和平衡等式 |
| 核心算法 | 生成四批投档、梯度、名额隔离、结转的代码草稿 | 先人工设计小数据集与逐轮预期，再运行对照；45 项测试通过 |
| 前端 | 生成页面结构、样式和交互代码草稿 | 浏览器逐页操作验证；截图保存于 `docs/images/` |
| 测试 | 生成 pytest 用例草稿和边界场景清单 | 人工推演预期写入 `tests/expected/`；测试结果人工复核 |
| 文档 | 生成报告、部署说明、演示脚本草稿 | 人工核对数字、截图、命令和限制说明 |

## 2. 未使用 AI 替代的工作

- 人工设计小数据集（2 初中、4 高中、17 考生）及逐轮推演；
- 人工构造两个高分滑档案例及志愿调整对照；
- 人工核对批次录取人数、计划余额、结转金额；
- 人工执行浏览器端到端演示；
- 人工确认所有姓名、学校、考号均为虚构数据。

## 3. 人工核验记录

1. **人工预期先行**：`tests/expected/small_expected.json` 与 `docs/测试材料.md` 的逐轮推演在引擎运行前完成；系统输出只用于对照。
2. **自动化测试**：`python -m pytest -q` 运行 45 项测试，覆盖梯度、志愿、同分、边界、自主招生、跨批次、名额隔离、结转、不足额、统计口径、异常输入、重复运行、滑档案例。
3. **一致性校验**：每次批次执行后运行 `verify_run`，检查唯一录取、计划不超额、名额平衡、有效志愿、计划内顺序。
4. **浏览器验证**：实际打开系统，完成“生成小数据集 → 新建运行 → 完整运行 → 查询 C07/C15 → 统计分析 → 滑档案例”全流程。
5. **数据核对**：小数据集最终录取 16 人、未录取 1 人（C15）、第一批/第二批各结转 1 人、G02 第三批最低分 640/末位 C12 660，与人工推演一致。

## 4. 责任说明

AI 生成内容仅作为草稿和辅助工具。项目成员对以下内容负责：

- 规则理解与实现是否符合任务书；
- 测试预期是否真实、未被系统输出反向填充；
- 提交的代码、数据、报告和演示是否可复现；
- 不伪造团队成员、分工、贡献占比或协作记录。

如发现 AI 生成内容与任务书冲突，以任务书为准，并在代码/文档中修正。

## 5. 未使用的内容

- 未使用真实考生个人信息；
- 未使用真实学校招生数据；
- 未伪造 Git 提交记录或团队成员；
- 未将系统输出当作人工预期。
