## 3. 提交前自检命令

```bat
cd zhongkao-admission
python -m pytest -q
python scripts/init_db.py --fixture small_main --force
python run.py
```

浏览器检查：

- [ ] 首页显示数据版本和最近运行；
- [ ] 数据管理六个标签均可打开；
- [ ] 小数据集完整运行四批人数 3/5/6/2；
- [ ] 计划余额与结转流水正确；
- [ ] 结果查询 C07、C15 原因正确；
- [ ] 统计分析最低分/末位考生分别显示；
- [ ] 滑档案例两个对照均可运行；
- [ ] CSV 导出可下载；
- [ ] 一致性校验通过；
- [ ] 数据锁定后修改输入返回 409；
- [ ] 创建新数据版本后可编辑。
